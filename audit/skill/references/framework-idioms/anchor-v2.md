# Anchor v2 (`anchor-next`, 2.0.0-rc) — audit notes

- **Unaudited alpha.** The docs-v2 index still says it is not on crates.io, but `anchor-lang` 2.0.0-rc.1 and 2.0.0-rc.2 are published there, and the published crate is this v2 crate (`lang-v2/` at the v2.0.0-rc tags; the old `lang/` is renamed `anchor-lang-v1` with `publish = false`). APIs may break between commits. A production `anchor-lang` git dependency on `branch = "anchor-next"` is unpinned and non-reproducible: recommend a `tag`/`rev`; report Informational/Low plus a trust assumption.
- **`unsafe(dup)`** replaces `dup` for duplicate mutable accounts — every use needs aliasing analysis.
- **Custom entrypoints** (`no-entrypoint` + hand-written `entrypoint`): fast-pathed discriminators skip **all** generated `TryAccounts` checks (account count, duplicate-mutable, owner, writable, signer, data length, PDA derivation, address); each must be re-implemented. Assembly fast paths hard-code agave account-layout offsets. `#[discrim = N]` is a one-byte **instruction** discriminator — values become ABI. Grep: `no-entrypoint` in `[features] default`, `__anchor_dispatch`, `#[no_mangle] pub unsafe extern "C" fn entrypoint`, `#[discrim`.
- **Raw access** (`.view()`, `borrow_unchecked_mut`): two live `&mut` to one account is UB; hard-coded offsets break on layout change; fully raw handlers restore count, discriminator, owner, writable, signer, borrow tracking and PDA checks themselves.
- **Feature flags:** `default-features = false` drops `guardrails`; `const-rent` bakes the rent formula in (stale on a rent change until redeployed); `idl-build` must not be enabled in deployed SBF binaries.
- **Serialisation (wincode vs Borsh):** `HashMap`/`HashSet` encode in iteration order (non-canonical — never hash, sign or byte-compare them); NaN floats accepted (validate finiteness) — in instruction data, constraint args, events and `#[account(borsh)]`.
- **Types:** v2 `Account<T>` requires `T: Pod` with no padding (compile-time); `BorshAccount<T>` for non-Pod; optional accounts can no longer be PDA seeds; imported bytemuck layouts with padding rejected (rc.2). v2 default account discriminators remain `sha256("account:"+name)[..8]`.
